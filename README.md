# Gerenciador de Tarefas (React)

Um aplicativo moderno, intuitivo e responsivo para organização e gerenciamento de tarefas diárias (To-Do List). Este projeto foi desenvolvido utilizando **React** para praticar o desenvolvimento baseado em componentes, gerenciamento de estados e ciclo de vida do ecossistema React.

---

## Tecnologias Utilizadas

O projeto foi construído utilizando o ecossistema moderno do React:

* **React:** Biblioteca JavaScript para construção de interfaces de usuário baseadas em componentes.
* **Hooks (useState, useEffect):** Utilizados para gerenciar o estado das tarefas (adicionar, concluir, remover) e para sincronizar os dados.
* **HTML5 & CSS3:** Estruturação semântica e estilização moderna da interface, garantindo que o app seja totalmente responsivo.
* **LocalStorage:** Persistência de dados diretamente no navegador do usuário (as tarefas não somem ao atualizar a página!).

---

## Funcionalidades

* **Criar Tarefas:** Adicione novas atividades dinamicamente.
* **Concluir Tarefas:** Marque ou desmarque tarefas como concluídas com atualização visual instantânea.
* **Remover Tarefas:** Exclua itens da lista de forma individual.
* **Salvamento Automático:** Integração com o LocalStorage para manter os dados salvos entre sessões.
